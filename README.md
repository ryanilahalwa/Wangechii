# Wangechii

A small deployed multimedia website that brings together photos and video in a simple, shareable web experience.

## Live demo

[Open Wangechii](https://wangechii.vercel.app)

## What it demonstrates

- Structuring a static website around multimedia content
- Organizing images and video assets for the web
- Deploying a project so it can be shared publicly

## Project structure

The `Wangechi/` directory contains the site entry point and its media assets.

## Status

This project is complete as a first deployed website and serves as a foundation for improving responsive design, accessibility, performance, and reusable components.
